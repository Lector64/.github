# Lector64

**Chess, as structured data.**

Lector64 analyses positions and games to identify defined chess objects and
connect them to the pieces, squares and moves involved.

It produces structured data for applications, teaching tools and game
exploration, within the documented scope of each version.

Lector64 is the computational system. [ChessGrammar](https://chessgrammar.com/)
is the reference that publishes definitions and examples for understanding
chess objects within the scope of its edition.
